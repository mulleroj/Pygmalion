# Visual Bible – Mrs Pearce

This reference is the canonical visual identity authority for Mrs Pearce in Chapter II. It is separate from `visual-bible-eliza.md`, which remains reserved for Eliza Doolittle and her canonical visual stages.

## Canonical visual lock

Mrs Pearce canonical visual set: `APPROVED / CANONICAL`

- Canonical master: `assets/images/characters/mrs-pearce/source/mrs-pearce_master.png`.
- Approved expression variants:
  - `practical-questioning`
  - `observant-support`
  - `fairness-monitoring`
  - `quiet-approval`
- Transparent runtime derivatives: `assets/images/characters/mrs-pearce/runtime/` — `TECHNICALLY VERIFIED`.

All five images represent the same mature Edwardian woman and must retain the same:

- face and approximate age;
- hairstyle and hair colour;
- clothing and Edwardian period identity;
- proportions and body shape.

The visual identity must not become a comic servant, caricature, modern figure, or upper-class stereotype. Mrs Pearce must remain visually distinct from Eliza while retaining a humane, grounded, practical presence.

## Runtime derivative rules

Runtime derivatives remove only the neutral source background needed for storybook compositing. They must preserve hair, lace, hands, apron, image content, canvas dimensions, proportions, and expression identity. They must not be used as canonical source masters.
