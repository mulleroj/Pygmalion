# Pygmalion Adventure skill

Použij tento repo-scoped skill při práci na příběhu, postavách, hlasech, jazykových aktivitách, assetech nebo herních pravidlech projektu `pygmalion-adventure`.

## Reference podle úkolu

- tvorba nebo úprava příběhu: načti `references/story-bible.md` a `references/game-design-rules.md`;
- Eliza nebo jiné character visuals: načti `references/visual-bible-eliza.md`;
- hlasy, ElevenLabs nebo audio assety: načti `references/audio-voice-bible.md`;
- jazykové aktivity: načti `references/language-learning-rules.md`;
- adaptace zdrojového příběhu, názvy nebo dialogy: načti `references/copyright-boundaries.md`.

Reference jsou vůči tomuto souboru relativní. Načti pouze ty, které odpovídají úkolu, a před změnou je přečti celé.

## Workflow

1. Zachovej schválenou charakterovou, hlasovou a herní kontinuitu; neměň ji bez explicitního požadavku.
2. Ověř copyright hranice, přístupnost a návaznost na vzdělávací cíl.
3. Nové zásadní rozhodnutí nejprve promítni do odpovídající bible.
4. Před vydáním ověř příběhová větvení, asset naming, transkripty a lokální ukládání progressu.

V bootstrap fázi nevytvářej UI ani aplikační kód. Bez výslovného požadavku neprováděj commit, push ani deploy.
