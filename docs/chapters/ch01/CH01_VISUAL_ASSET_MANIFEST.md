## Rules

- The canonical asset root is the existing `assets/` directory; no parallel asset root is valid.
- Runtime uses WebP. PNG files are preserved as source mastery where available.
- Eliza Flower Girl identity is `APPROVED / LOCKED` and all five variants represent the same Eliza.
- Higgins, Pickering, and Freddy masters are approved canonical character references.
- Alternate/reference files must not be promoted to canonical without explicit approval.
- No asset intentionally copies a specific *My Fair Lady* performer or film staging.
